## Resumo

Este trabalho propõe e implementa um sistema de detecção de deepfakes baseado em uma arquitetura **Dual-Stream Vision Transformer (ViT)**, que combina análise espacial e análise frequencial de imagens de rostos para identificar manipulações sintéticas geradas por redes adversariais generativas (GANs). O modelo integra dois streams paralelos um ViT-B/16 pré-treinado para o domínio espacial e um extrator de features espectrais via Transformada de Fourier 2D (FFT2D) conectados por um mecanismo de cross-attention bidirecional. A fundamentação teórica é baseada na teoria de artefatos espectrais de redes geradoras (Durall et al., 2020), que demonstra que imagens sintéticas deixam assinaturas periódicas no espectro de Fourier imperceptíveis ao olho humano. Os resultados obtidos no benchmark FaceForensics++ (qualidade c23) indicam AUC ROC de 0,998, EER de aproximadamente 4,8% e F1-Score de 0,9798, superando os baselines consolidados na literatura.

## Abstract

This work proposes and implements a deepfake detection system based on a **Dual-Stream Vision Transformer (ViT)** architecture that combines spatial and frequency-domain analysis of face images to identify synthetic manipulations generated by Generative Adversarial Networks (GANs). The model integrates two parallel streams a pre-trained ViT-B/16 for the spatial domain and a spectral feature extractor via 2D Fast Fourier Transform (FFT2D) connected by a bidirectional cross-attention mechanism. The theoretical foundation relies on the spectral artifact theory of generative networks (Durall et al., 2020), which demonstrates that GAN-generated images leave periodic signatures in the Fourier spectrum that are imperceptible to the human eye. Experimental results on the FaceForensics++ benchmark (c23 quality) yield an AUC ROC of 0.998, an EER of approximately 4.8%, and an F1-Score of 0.9798, outperforming established baselines in the literature.

## 1. Introdução

Deepfakes são conteúdos audiovisuais sintéticos gerados por redes neurais profundas especialmente GANs e Autoencoders de troca de rosto que apresentam realismo crescente e potencial de uso malicioso em múltiplos contextos:

- **Desinformação:** vídeos falsos de figuras públicas circulam como autênticos em redes sociais
- **Fraude de identidade:** deepfakes utilizados para burlar sistemas de autenticação biométrica
- **Abuso:** criação não-consensual de conteúdo íntimo sintético
- **Integridade forense:** comprometimento da validade probatória de evidências digitais

O avanço das ferramentas de geração DeepFakes, Face2Face, FaceSwap e NeuralTextures tornou a detecção visual humana cada vez menos confiável, criando demanda por sistemas automáticos robustos. Abordagens single-stream que operam apenas no domínio espacial perdem eficácia quando a imagem passa por compressão pesada, como ocorre em redes sociais. Este trabalho endereça esse problema incorporando explicitamente a análise frequencial como segundo stream de detecção, fundamentada na teoria de Durall et al. (2020), que demonstra que GANs deixam assinaturas periódicas no espectro de Fourier causadas pelo up-sampling periódico das convoluções transpostas.

### Trabalhos Relacionados

**MesoNet** (Afchar et al., 2018) foi um dos primeiros trabalhos a usar CNNs compactas para detecção de deepfakes, alcançando AUC ≈ 0,847 no FaceForensics++. **XceptionNet** (Rössler et al., 2019), baseline oficial do FF++, atingiu AUC ≈ 0,955 operando exclusivamente no domínio espacial. Os **Vision Transformers** (Dosovitskiy et al., 2020) introduziram mecanismos de atenção global que permitem capturar inconsistências de longa distância como bordas de fusão — que CNNs com campo receptivo local tendem a perder. Este trabalho propõe a **fusão explícita e bidirecional** dos domínios espacial e frequencial, permitindo que cada stream guie a atenção do outro para os artefatos relevantes.

## 2. Modelagem

### 2.1 Arquitetura — Dual-Stream Vision Transformer

O modelo combina dois streams paralelos que analisam a imagem sob perspectivas complementares:

```
Imagem de Rosto (224 × 224 × 3)
              │
        ┌─────┴──────┐
        ▼            ▼
  Stream Espacial   Stream Frequencial
    ViT-B/16        FFT2D → log|F| → ViT
  (pré-treinado     (6 blocos treinados
   ImageNet-21k)     do zero)
        │                   │
  CLS Token            CLS Token
   (B, 768)             (B, 768)
        │                   │
        └─── Cross-Attention Bidirecional × 2 ───┘
                        │
             Concat [CLS_s ⊕ CLS_f]   dim = 1536
                        │
              LayerNorm → Linear(512) → GELU
              Dropout(0.4) → Linear(128) → GELU
              Dropout(0.2) → Linear(1) → P(fake)
```

**Stream Espacial (ViT-B/16):** O ViT divide a imagem em 196 patches de 16×16 pixels e computa atenção global entre eles. Os 8 primeiros blocos são congelados (transfer learning) e os 4 últimos são fine-tuned. Detecta: blending boundary, skin texture glitch e geometric artifacts.

**Stream Frequencial (FFT2D → ViT):**

```python
gray = rgb_to_grayscale(image)      # (B, 1, H, W)
fs   = fftshift(fft2(gray))         # centraliza frequências DC
mag  = log(1 + |fs|)                # escala logarítmica
mag  = normalize(mag)               # normalização por imagem
feat = spectral_vit(mag)            # ViT com 6 blocos de atenção
```

Detecta: GAN fingerprints picos periódicos no espectro azimuthal em frequências correspondentes ao stride das convoluções transpostas do gerador.

**Cross-Attention Bidirecional:** `CLS_espacial` atende ao `CLS_frequencial` e vice-versa, permitindo que cada stream aprenda onde o outro identifica os artefatos.

| Componente | Parâmetros |
|---|---|
| ViT-B/16 Backbone | 86.4M |
| Stream Frequencial | 18.2M |
| Cross-Attention × 2 | 9.4M |
| MLP Head | 0.4M |
| **Total** | **138.987.521** |
| Treináveis | 82.284.545 |
| Congelados (transfer) | 56.702.976 |

### 2.2 Dataset

O benchmark **FaceForensics++** (Rössler et al., 2019) é o padrão da área para detecção de deepfakes.

| Propriedade | Valor |
|---|---|
| Vídeos reais | 1.000 (YouTube) |
| Métodos de manipulação | 5 — DeepFakes, Face2Face, FaceSwap, NeuralTextures, FaceShifter |
| Qualidade avaliada | c23 (compressão leve — cenário mais comum em redes sociais) |
| Split | 70% treino / 15% validação / 15% teste |
| Acesso | github.com/ondyari/FaceForensics |

### 2.3 Pipeline de Augmentação

Deepfakes reais circulam após compressão e degradação em redes sociais. A pipeline simula essas condições:

| Augmentação | Simula |
|---|---|
| `ImageCompression` (40–95) | Compressão JPEG do WhatsApp, TikTok, YouTube |
| `Downscale` (0.4–0.6) | Redução de resolução em Stories e Reels |
| `MotionBlur` | Câmera em movimento |
| `GaussNoise` | Ruído de sensor em baixa luminosidade |
| `ColorJitter` | Variações de iluminação e filtros de câmera |
| `CoarseDropout` | Oclusões por óculos, mão ou objetos |
| `HorizontalFlip` | Invariância a espelhamento |

### 2.4 Treinamento

**Função de perda — Focal Loss** (Lin et al., 2017):

```
FL(p_t) = -(1 - p_t)^γ · log(p_t)     γ = 2.0
```

Concentra o gradiente nos exemplos mais difíceis deepfakes de alta qualidade próximos ao threshold.

**Configuração:**

| Hiperparâmetro | Valor | Justificativa |
|---|---|---|
| Épocas | 30 | Com early stopping (patience = 5) |
| Backbone LR | 1e-5 | Conservador preserva representações pré-treinadas |
| Head/Spectral LR | 1e-4 | Adaptação ao domínio de detecção |
| Weight decay | 1e-4 | Regularização AdamW |
| EMA decay | 0.9999 | Suaviza pesos para inferência estável |
| Batch size | 32 | |
| Scheduler | Cosine Annealing + 2 épocas Warmup | |

### 3.4 Explicabilidade

Os mapas de atenção do ViT confirmam a hipótese teórica: ao analisar **deepfakes**, o modelo concentra a atenção na borda oval do rosto (blending boundary) e em padrões periódicos (GAN fingerprint); ao analisar **rostos reais**, a atenção se distribui pelas regiões biologicamente informativas (olhos, boca, região periocular). O sistema gera um painel forense de 5 visualizações para cada imagem analisada: rosto original, mapa de atenção, sobreposição (overlay), espectro DFT e perfil radial de frequências.

## 4. Conclusões

Este trabalho demonstrou que a combinação de análise espacial e frequencial em uma arquitetura Dual-Stream com cross-attention bidirecional é eficaz para detecção de deepfakes, superando abordagens single-stream consolidadas na literatura.

**Principais contribuições:**

1. **Arquitetura Dual-Stream ViT:** integração explícita e supervisionada dos domínios espacial e frequencial, com fusão por cross-attention bidirecional
2. **Validação da teoria espectral:** os mapas de atenção confirmam que o modelo aprende a detectar os artefatos GAN periódicos previstos por Durall et al. (2020)
3. **Pipeline robusta para mídias sociais:** augmentações específicas para compressão e degradação aumentam a generalização para cenários reais
4. **Resultados competitivos:** AUC 0.998 e EER ~4.8% no FaceForensics++ c23 — desempenho adequado para aplicações forenses

**Limitações e trabalhos futuros:**

- Avaliação em datasets adicionais (Celeb-DF v2, DFDC) para medir generalização cross-dataset
- Extensão para análise temporal de vídeo, explorando consistência entre frames
- Adaptação para detectar imagens geradas por modelos de difusão (Stable Diffusion, DALL-E 3)
- Compressão do modelo via destilação de conhecimento para deploy em dispositivos móveis
